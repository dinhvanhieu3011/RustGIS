# Circular 12 land-use layers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command (`landuse.tt12`) turns a polygon layer into a Circular 12 land-use layer: `layer` code field, codes from Vietnamese names, the SLD's colours and image fills by scale, one feature template per group.

**Architecture:** The 36 groups (codes, colours, image names, Vietnamese names) are a built-in table in a new `rustgis-map` module `tt12`, transcribed once from `QH_SDD_TT12BXD.xml`. The layer keeps a normal `Renderer::Unique` on `layer` (one class per code, so colours, legend and the GPU path work unchanged) plus a new `Layer::tt12: bool` flag. The CPU renderer, for flagged layers at 1:10,000 or closer, swaps the solid fill for a tiled image read from `img/` and cached; the GPU path sends flagged layers at image scales to the CPU branch.

**Tech Stack:** Rust, tiny-skia `Pattern` (`SpreadMode::Repeat`), `image` crate (already a `rustgis-render` dependency), serde.

**Spec:** `docs/superpowers/specs/2026-10-26-tt12-land-use-design.md`

## Global Constraints
- No `unwrap()`/`expect()`/`panic!`/indexing on hostile input in non-test code; no `unsafe`.
- Everything below `apps/` builds for `wasm32-unknown-unknown`; image loading is `#[cfg(not(target_arch = "wasm32"))]`, the web gets colour only.
- User-visible strings through `tl!` / `i18n::fmt`; command ids never translated.
- `cargo xtask ci` green before each commit. `ATTRIBUTION.md` rows for `img/` are skipped (fork only).
- Field name `layer`, text type. Image scale threshold 10,000 (`scale <= 10_000.0` → images). General outline `#4D4D4D`.
- `CDO03` → CXO, `BDX01` → MNC (later SLD rule wins). DNL image-scale outline `#FFBF7F`; every other group outlines in its fill colour at image scales.
- Unknown codes: fill `rustgis_map::symbology::OTHER_FILL`, legend `<all other values>`.

## Review Focus
- Codes with stray case/spaces (`" odv01"`): match after `trim()` + ASCII uppercase; test in Task 1.
- Running `landuse.tt12` twice: no duplicate templates, existing codes untouched, still one undo step; test in Task 3.
- Layer already has a non-text `layer` field (e.g. integer): error, nothing changed; test in Task 3.
- Corrupt / huge PNG in `img/`: falls back to colour, cache remembers the failure (no reload per frame), size capped at 1024×1024; test in Task 4.
- Point or line layer: command refuses ("Circular 12 styles polygon layers"); test in Task 3.

### Task 3: The `landuse.tt12` command

**Files:**
- Create: `crates/engine/src/cmd/landuse.rs`
- Modify: `crates/engine/src/cmd/mod.rs` (`mod landuse;`, `v.extend(landuse::commands());`)
- Test: `crates/engine/src/tests.rs`

**Interfaces:**
- Consumes: `tt12::{GROUPS, FIELD, group_of, group_by_name, renderer}`, `Layer::tt12`, `FeatureTemplate`.
- Produces: command `landuse.tt12`, label "Circular 12 Land Use", place "Data › Data Design › Fields" (Task 5 adds the ribbon button), `.when(need_feature_layer)`, params `{"layer"?, "nameField"?: string}`. Returns `{"matched": n, "unmatched": n, "kept": n, "templates": 36}`.

Behaviour (one mutating command, so one undo snapshot):
1. Polygon layer only, else `Err("Circular 12 styles polygon layers")`.
2. `layer` field missing → `ensure_field(FIELD, Text)`; present but not Text → `Err("the field 'layer' isn't text")` before any change.
3. `nameField` given: unknown → `Err`. For each row whose `layer` is empty: `group_by_name(value)` → write group code (`matched`), else leave empty (`unmatched`, only when the name itself isn't empty). Rows with a code already → `kept`.
4. `renderer = tt12::renderer()`, `tt12 = true`.
5. Templates: remove any whose name ends with `" ({code})"` for a group code, then push 36 `FeatureTemplate { name: "{name} ({code})", description: "", defaults: vec![(FIELD, Value::Text(code))] }`.
